Index Prices API

Правила пользования системой и примеры запросов к эндпоинтам цен

Получить последнюю цену GET

Возвращает самую актуальную (последнюю) запись цены для указанного тикера.

/api/v1/latest?ticker=btc_usd
Получить историю всех цен GET

Возвращает полный массив исторических данных по запрашиваемому тикеру.

/api/v1/all?ticker=eth_usd
Фильтрация по дате GET

Позволяет отфильтровать метрики цен для конкретного тикера на определенный день.

/api/v1/filter?ticker=btc_usd&date=2026-10-22
